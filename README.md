GitHub Pages 정적 앱입니다. DB나 학생 계정 없이 운영합니다.

- 활동 글·완성 작품: 지정 패들렛에 게시합니다. 박물관 작품 사진과 아쿠아리움 관찰 사진처럼 활동 기록에 필요한 이미지는 게시물에도 첨부합니다.
- 날짜별 사진 미션: 날짜당 카드 하나, 번호 목록 세 가지, 해당 날짜 Google Drive 버튼 하나입니다.
- 자유 여행 사진: 별도의 친구들과 함께 찍은 사진 공유 Drive 버튼입니다.
- 여행 안내: 조원·방 배치·비상 연락처 화면은 준비했으나 공개 배포 확인 대기 중입니다. 현재 배포 소스에 해당 정보는 포함하지 않습니다.
- 만나는 장소: 교사 제공 이미지 기준으로 표시합니다.
- 컬러헌팅: 개인 6색 랜덤 뽑기, 저장 없음. 사진 8장과 중앙 제목 칸으로 구성하며, 캔바의 본인 번호 페이지를 편집하고 완성 이미지 한 장을 패들렛에 게시합니다. 원본은 3일차 사진 Drive에 올립니다.
- 활동 설명: 2026-11-16 제공된 패들렛 활동 안내 PDF 기준으로 반영했습니다. 수학문화관은 체험 활동·수학적 특징·새롭게 알게 된 점과 느낀 점, 돌아오는 길은 여행 소감·친구에게 전하는 말을 작성합니다.
- 박물관·페어플레이·연극 글 다듬기 도구는 현재 탭에서만 초안을 유지합니다. 복사해서 패들렛에 게시해야 제출됩니다.
- 일정·서울 날씨·단체사진 포즈 18가지를 제공합니다. 날씨만 1시간 로컬 캐시합니다.

Drive 파일 업로드 권한과 Google 로그인, Padlet 방문자 쓰기 권한은 각 서비스에서 적용됩니다. 앱은 해당 권한을 변경하지 않습니다.
