# 우리의 가을, 우리의 수학여행

## 최종 운영 구조
GitHub Pages에서 일정·활동안내·날씨·색뽑기·사진포즈를 제공하고, 모든 글·사진·작품 제출은 사용자가 지정한 패들렛 한 곳으로 통일합니다.
Firebase/Google Sheets/Cloudflare Worker/Drive 연결 없이 운영합니다. 학생 로그인·이름등록·여행자명단·개인기록·교사DB관리 화면을 제거했습니다. 별도의 유료DB가 필요 없습니다. 패들렛의 요금제와 게시/업로드 권한은 별도 적용됩니다.

패들렛: https://padlet.com/aijne/padlet-s025i7i6mcmw61ynivge

## 화면
- 첫화면: 날짜별 일정요약·미션·서울날씨.
- 미션: 장소별안내와 패들렛버튼. 국중박3칸/페어플레이문장완성/연극10문장이상은 브라우저에서 글을 다듬고 복사하는 도구이며, 패들렛에 붙여넣고 게시해야 제출됩니다.
- 사진: 날짜별카드1개 안에 번호목록3개, 패들렛버튼1개. 카드3개를 따로 만들지 않습니다.
- 포즈: 실루엣18종 안내이미지2장, 클릭확대.
- 올림픽공원: 6색중동일확률개인뽑기, 저장없음. 캔바3×3완성작품을 패들렛에 제출.
- 스티커: 미리클AI와패들렛, 학생실제제작안내.

사진앨범은 게시물당최대6장. 컬러헌팅원본9+완성1은 첫글완성1+원본1~5, 둘째글원본6~9로 구분합니다.

## 저장·주의점
앱에는 학생데이터를저장하는서버/DB/인증/분석전송이 없습니다. 글정리초안은 현재탭의메모리에만 유지되고 새로고침하면 사라집니다. 색뽑기도 새로고침하면 초기화됩니다.
날씨예보만기기에1시간캐시합니다. 기존버전의브라우저체험기록은 임의삭제하거나패들렛으로자동전송하지않습니다. 이전Firebase프로젝트/드라이브/AppsScript는접속하거나수정하지않았습니다.
학생이로그인없이게시하려면패들렛방문자쓰기권한을설정하고제목에이름을적도록안내합니다. 이설정은앱에서자동변경하지않습니다. 게시물확인·피드백·공개·삭제는패들렛에서관리합니다.

## 개발·배포
의존성없는HTML/CSS/ES모듈입니다. `npm test`로핵심활동규칙을확인합니다. `.github/workflows/pages.yml`이web디렉터리를배포하고모든로컬모듈에커밋버전을붙입니다.
